Quickstart

Step 1 — Get your Anthropic API key

Create a free account at console.anthropic.com and grab your API key. You pay only for what your bot uses. New accounts get free credits.

Step 2 — Add this to your website

Paste this snippet before the closing </body> tag:

<!-- Orion Assistant: your API key lives here, never shared -->
<script>
  window.OrionConfig = {
    apiKey:        "sk-ant-api03-YOUR-KEY-HERE",  // required
    botName:       "MyBot",
    subtitle:      "Ask me anything",
    primaryColor:  "#534AB7",
    systemPrompt:  "You are a helpful assistant for MyWebsite. Answer questions about our products clearly and concisely.",
    welcomeMessage: "Hi! I'm MyBot 👋 How can I help?",
    knowledgeBase: [
      { q: "What are your opening hours?", a: "We're open Mon–Sat, 9am–6pm." },
      { q: "Do you offer refunds?",         a: "Yes, full refund within 30 days." }
    ]
  }
</script>
<script src="orion.js"></script>

That's it. A chat bubble appears in the corner. ✅

Customization options
Branding

Bot name & color

Set botName and primaryColor to match your brand. The widget auto-derives hover and accent shades.

AI Persona

System prompt

Define the bot's personality, scope, and rules in plain English. The bot follows it on every message.

Knowledge

Knowledge base

Add Q&A pairs to teach the bot about your business — hours, pricing, policies, FAQs — without any fine-tuning.

Layout

Position

Set position: "left" or "right" to place the launcher where it fits your layout.

Security note

⚠️ API key exposure

With this client-side setup, the API key is visible in the browser's source code. This is fine for personal projects, internal tools, or quick prototypes. For production public websites, the recommended approach is to route calls through a lightweight backend proxy (Node.js / Python / Vercel function) that holds the key server-side. See the proxy-server/ folder in this repo for a ready-to-deploy example.
