Quickstart

Step 1 — Get your Anthropic API key

Create a free account at console.anthropic.com and grab your API key. New accounts receive free credits.

Step 2 — Paste this before </body>

<!-- Orion Assistant — add before </body> -->
<script>
  window.OrionConfig = {
    apiKey:        "sk-ant-api03-YOUR-KEY-HERE",
    botName:       "Orion",
    subtitle:      "Ask me anything",
    primaryColor:  "#534AB7",
    systemPrompt:  "You are a helpful assistant for MyWebsite.",
    pages: [
      { title: "Enroll Now",  url: "/enroll",  keywords: ["enroll", "register", "sign up"] },
      { title: "View Courses", url: "/courses", keywords: ["courses", "programs"] },
      { title: "Pricing",      url: "/pricing", keywords: ["price", "cost", "fee"] },
      { title: "Contact Us",   url: "/contact", keywords: ["contact", "support"] }
    ],
    knowledgeBase: [
      { q: "What are your hours?", a: "Mon–Sat, 9am–6pm." }
    ]
  }
</script>
<script src="orion.js"></script>

✅ A chat bubble appears in the corner. That's it.

Smart Page Routing NEW

What it does

When a user asks something that matches one of your pages, Orion automatically appends a clickable button to its reply that takes the user directly to that page — just like AtomBot.

How to configure

Add a pages array to your config. Each entry has a title, URL, and keywords:

pages: [
  {
    title:    "Enroll Now",         // Button label
    url:      "/enroll",            // Where the button links
    keywords: ["enroll", "register", "sign up", "join"]
  },
  {
    title:    "Pricing",
    url:      "/pricing",
    keywords: ["price", "cost", "fee", "how much"]
  }
]

How routing works (two layers)

Layer 1 — Claude decides: The AI reads your pages list and decides when a button is genuinely helpful. It picks the right page and appends it to its reply automatically.

Layer 2 — Keyword fallback: If Claude doesn't route but the user's message contains a keyword match, the widget adds the button client-side. No extra API calls.

Security note

⚠️ API key visibility

With client-side setup the API key is visible in browser source. Fine for internal tools, prototypes, and low-traffic sites. For public production sites, use the proxy server in proxy-server/ — it holds your key server-side and the widget calls your proxy instead of Anthropic directly.
